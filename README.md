# PIA Port Forward Automatic Configuration - Docker mod for transmission

This mod automatically configures the listen port in transmission to match the forwarded port from PIA when using thrnz's docker-wireguard-pia container for networking.

In transmission arguments, set an environment variable `DOCKER_MODS=linuxserver/mods:transmission-pia-pf`

If adding multiple mods, enter them in an array separated by `|`, such as `DOCKER_MODS=linuxserver/mods:transmission-pia-pf|linuxserver/mods:transmission-floodui`

## Requirements

* thrnz's [docker-wireguard-pia](https://github.com/thrnz/docker-wireguard-pia)
* mount the volume where the port file generated by docker-wireguard-pia is located. (default is `/pia-shared/port.dat`. You can override this by specifying the ENV variable `PORT_FILE`)

## Example Docker Compose

      *Example Docker Compose YAML Configuration*

      ```yaml
      version: "2.1"
      services:
        radarr:
          image: lscr.io/linuxserver/radarr
          container_name: radarr
          environment:
            - PUID=1000
            - PGID=1000
            - TZ=America/Chicago
            - DOCKER_MODS=linuxserver/mods:radarr-striptracks
          volumes:
            - /path/to/data:/config
            - /path/to/movies:/movies
            - /path/to/downloadclient-downloads:/downloads
          ports:
            - 7878:7878
          restart: unless-stopped
      ```  

      <details>
      <summary>Example Docker Run Command</summary>

       ```shell
       docker run -d \
         --name=radarr \
         -e PUID=1000 \
         -e PGID=1000 \
         -e TZ=America/Chicago \
         -e DOCKER_MODS=linuxserver/mods:radarr-striptracks \
         -p 7878:7878 \
         -v /path/to/data:/config \
         -v /path/to/movies:/movies \
         -v /path/to/downloadclient-downloads:/downloads \
         --restart unless-stopped \
         lscr.io/linuxserver/radarr
       ```
